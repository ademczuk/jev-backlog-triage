Backlog triage with jev

Each row is sent as state to typesafe-ai/jev on Vercel AI Gateway with three closed questions. Nothing is generated; every answer is a probability over options defined up front. Rows below 0.70 confidence go to a person.

Frontend on GitHub Pages; the jev call runs in a Vercel function that holds the key. Source: ademczuk/jev-backlog-triage.
