# Data sources

Every set here is public. Files marked "not committed" are regenerated by the script named, with the
same seed, so the committed results rows (ids, labels and model outputs, no text) still line up.

| file | source | license | committed | built by |
|---|---|---|---|---|
| telco.jsonl, telco.eval.csv, telco_hostile.jsonl | IBM Telco Customer Churn (github.com/IBM/telco-customer-churn-on-icp4d) | Apache-2.0 | yes | prep_tabular.py |
| telco.train.csv | same | Apache-2.0 | no, regenerable | prep_tabular.py |
| bank.jsonl, bank.eval.csv | UCI Bank Marketing, Moro, Cortez and Rita (2014), archive.ics.uci.edu/dataset/222 | CC BY 4.0 | yes | prep_tabular.py |
| bank.train.csv | same | CC BY 4.0 | no, regenerable | prep_tabular.py |
| banking77.jsonl, banking77.labels.json | PolyAI Banking77, Casanueva et al. (2020) | CC BY 4.0 | yes | prep_data.py |
| sst2.jsonl | Stanford Sentiment Treebank, GLUE SST-2 validation (stanfordnlp/sst2) | redistribution terms unclear | no | prep_data.py |
| irony.jsonl | TweetEval irony test (cardiffnlp/tweet_eval), tweet text | tweet text, not redistributed | no | prep_data.py |
| routing.jsonl, routing.train.jsonl | RouterBench 0-shot (withmartian/routerbench) | not stated | no | prep_harness.py |
| tools.jsonl, tools.options.json | MetaTool (github.com/HowieHwong/MetaTool) | MIT | yes | prep_harness.py |
| tools.train.jsonl | same | MIT | no, regenerable | prep_harness.py |
| injection.jsonl | deepset/prompt-injections, test split | Apache-2.0 | yes | prep_harness.py |
| injection.train.jsonl | same, train split | Apache-2.0 | no, regenerable | prep_harness.py |

Bank Marketing's `duration` column is dropped (UCI marks it as outcome leakage). telco_hostile.jsonl is
50 Telco rows with one sentence appended, written for the injection test in PROTOCOL.md.
